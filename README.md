# wake-audio

Private wake audio for Jarvis Morning Shortcut (Rowan MP3).
Updated by Chief of Staff each weekday ~5:50a PT.

## iPhone Shortcuts

Prefer binary `.mp3` raw URLs when available. Until then:

1. **Get Contents of URL** → `https://raw.githubusercontent.com/joshhair/wake-audio/main/morning.mp3.b64` (or `ambient.mp3.b64` / `.part0`+`.part1`+`.part2`)
2. **Base64 Decode** (get file)
3. **Play Sound** / Save to Files

If using parts: Get each part, join text in order, then Base64 Decode.
